# 🎬 Movie Recommendation System

This project is a collaborative filtering and content-based filtering recommendation system built using machine learning and neural networks. It predicts user ratings for movies and finds similar items based on user and item features.

---

##  Technologies & Tools

* **Python**
* **TensorFlow / Keras** (for neural network models and custom training loops)
* **NumPy** (for matrix operations and mathematical computations)
* **Pandas** (for data management)

---

##  Key Features

1. **Cost Function Calculation (`cofi_cost_func`):** Implementation of the collaborative filtering cost function with regularization from scratch.
2. **Neural Network Architecture (Functional & Sequential API):** Dual-network structure (`user_NN` and `item_NN`) to learn user and item embeddings.
3. **Distance Calculation (`sq_dist`):** Calculating the squared distance between feature vectors to find the most similar movies.
4. **Cold Start Problem Analysis:** Understanding and identifying scenarios related to the cold start problem in recommendation systems.
